# Student Companion App - APK Distribution Guide

## 🎓 About Student Companion

Student Companion is a comprehensive mobile application designed to enhance the educational experience for students and administrators. Built with Flutter for cross-platform compatibility, it provides a seamless experience on Android devices.

## ✨ Key Features

### For Students:

- **📚 Assignment Management**: Track tasks with priority levels and deadlines
- **📅 Schedule Viewing**: Access class schedules organized by sections
- **🤖 AI Study Assistant**: Get help with:
  - Task prioritization and workload analysis
  - Study suggestions and smart reminders
  - Q&A support and personalized study plans
  - Quiz generation and content summarization
- **📢 Announcements**: Receive targeted announcements from administrators
- **💬 Discussion Forums**: Participate in academic discussions
- **📖 Study Materials**: Access learning resources
- **🔔 Notifications**: Stay updated with local notifications

### For Administrators:

- **👥 User Management**: Approve registrations and manage user roles
- **📊 Dashboard**: Monitor system health and user statistics
- **📝 Content Moderation**: Oversee discussions and content
- **📋 Schedule Management**: Create and manage class schedules
- **📢 Targeted Announcements**: Send announcements to specific departments/batches/sections
- **📊 Log Monitoring**: Track system activities
- **🏢 Organization Management**: Manage departments, batches, and sections

## 🔒 Security & Access Control

- **Role-based Access**: Admin features restricted to administrators only
- **Data Isolation**: Users can only access their own data
- **Targeted Content**: Announcements filtered by academic groups
- **Secure Authentication**: JWT-based authentication system

## 📱 Installation Instructions

### Prerequisites:

- Android device running Android 5.0 (API level 21) or higher
- At least 100MB free storage space

### Installation Steps:

1. **Download the APK file** from the provided link
2. **Enable Unknown Sources**:
   - Go to Settings → Security/Privacy
   - Enable "Install from unknown sources" or "Install unknown apps"
3. **Install the APK**:
   - Open the downloaded APK file
   - Tap "Install" when prompted
   - Wait for installation to complete
4. **Launch the App**:
   - Open "Student Companion" from your app drawer
   - Login with your credentials (provided by administrator)

### First Time Setup:

- The app will request permissions for notifications and storage
- Grant these permissions for full functionality
- Configure your profile if required

## 🔧 Troubleshooting

### Installation Issues:

- **"App not installed"**: Ensure you enabled "Install from unknown sources"
- **"Parse error"**: The APK file may be corrupted, try downloading again
- **Storage space**: Free up space if installation fails

### Runtime Issues:

- **Can't login**: Check internet connection and verify credentials
- **No notifications**: Ensure notification permissions are granted
- **App crashes**: Try clearing app data or reinstalling

### Network Issues:

- **API connection failed**: Ensure the backend server is running
- **Slow loading**: Check internet connection speed
